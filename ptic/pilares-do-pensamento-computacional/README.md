# Projeto de Pesquisa – Pilares do Pensamento Computacional

## Descrição
Este projeto apresenta uma pesquisa sobre os pilares do Pensamento Computacional, abordando seus conceitos, aplicações e importância na resolução de problemas.

## Objetivos
- Compreender os pilares do Pensamento Computacional.
- Explicar cada pilar e sua função.
- Demonstrar aplicações práticas desses conceitos.
